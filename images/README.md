# Project images

This directory contains the final graphics prepared for the StoryMap and repository documentation.

## Featured figures

- `data_preparation_workflow.png` and `.svg` — source-data preparation workflow
- `priority_model_weights.png` and `.svg` — nine criteria and documented weights
- `prioritization_workflow.png` and `.svg` — transition from prepared inventory to Year 1 selection
- `year1_dashboard_mobile.png` — mobile-friendly dashboard alternative
- `project_thumbnail.png` — illustrative portfolio thumbnail used for project presentation

## Limitations

The `limitations/` directory contains the four individual limitation cards and their combined overview.

## Alternate figure

`alternate/inspection_priority_index_inputs.png` is an earlier overview of the model inputs. It is retained as a project-design artifact but is not featured in the README because the later weights and workflow figures communicate the final model more precisely.

The project thumbnail is an illustrative composite rather than an analytical map and should not be interpreted as showing exact modeled locations or values.
